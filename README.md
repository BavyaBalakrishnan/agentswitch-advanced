# AgentSwitch Advanced seats

Eight student teams build agents for the AgentSwitch platform, one folder per seat:
28 EA, 29 Document Intake, 30 Market Research, 31 Order-to-Cash Watcher, 32 Compliance Calendar, 33 Red Team, 34 Eval Harness, 35 Data Steward.

You work 6 to 8 hours a week until the end of December.

## What is in this repository
Only your own work: agent code, tests, notes. **No AgentSwitch source code is in this repository and none may be added.** The platform is private. Do not copy, paste or commit platform code, schemas, database files or screenshots of internal screens.

## Rules
1. Work in your own fork. Fork this repository, make a branch in your fork, and open a pull request into `main`. Nobody pushes to `main` directly; students have read access only.
2. Each pull request needs one review from another person on your seat or the Eval Harness seat. Then the seat lead merges it. Do not merge your own pull request.
3. Never commit passwords, tokens, API keys or `.env` files. If you do by mistake, tell the course team at once so the credential can be replaced.
4. Your agent proposes and drafts; a person approves anything that changes a record or reaches a customer.
5. Do not delete or overwrite data you did not create. Report problems in the bug-report format.
6. Each login has a daily token budget. Keep your agent efficient.
